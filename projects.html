Email Spam Classifier

↗ GitHub repository
Description

Developed a machine learning model to classify emails as spam or not spam using a labeled dataset. Email text was preprocessed and converted into numerical features using TF-IDF, then classified with Multinomial Naive Bayes, achieving 95% accuracy.

Technologies
  • Python · Jupyter Notebook
  • Pandas, Scikit-learn
Outcome

A lightweight spam filter that flags unwanted emails accurately with minimal preprocessing overhead.

Audio Classification Model

↗ GitHub repository
Description

Built a deep learning model to classify audio types using the UrbanSound8k dataset. MFCC features were extracted and fed into a TensorFlow Sequential model, reaching 80% accuracy, then deployed via Flask for real-time predictions.

Technologies
  • Python · TensorFlow · Flask
  • Librosa, Scikit-learn
Outcome

A dependable audio classifier that turns raw sound into structured predictions, ready to plug into a real-time interface.

Car Price Predictor

↗ GitHub repository
Description

Created a model to predict used car prices from key features. Categorical features were OneHotEncoded and fed into a Linear Regression pipeline, achieving 86% accuracy, then served through a Flask app.

Technologies
  • Python · Flask
  • Pandas, NumPy, Scikit-learn
Outcome

A streamlined pricing tool that gives instant, data-backed estimates for used car resale value.
